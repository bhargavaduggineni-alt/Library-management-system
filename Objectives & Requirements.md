Objectives & Requirements

 Objectives

- To develop a simple Library Management System using Python.
- To manage books efficiently.
- To allow users to add, view, search, issue, return, and delete books.
- To provide library statistics.
- To make library operations simple and user-friendly.

 Requirements

 Software Requirements

- Python 3.x
- Visual Studio Code or any Python-supported IDE
- Windows, Linux, or macOS

 Functional Requirements

- Add new books
- View all books
- Search for books
- Issue books
- Return books
- Delete books
- View issued books
- View library statistics

Technical Requirements

- Python programming language
- Basic Python concepts such as functions, lists, loops, conditions, and input/output
