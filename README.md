Library Management System

About the Project
This is a Python-based Library Management System that helps manage books in a library through a simple menu-driven program.

 Features
- Add new books
- View all books
- Search for books
- Issue books
- Return books
- Delete books
- View issued books
- View library statistics

Technology Used
- Python

 How to Run
1. Install Python on your computer.
2. Download or clone this repository.
3. Open the project in VS Code.
4. Run the Python file.
