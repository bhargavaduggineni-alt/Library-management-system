                                           📚 Library Management System

## 📌 About the Project

The **Library Management System** is a Python-based project developed to manage the basic activities of a library in a simple and organized way.

The system allows users to add, view, search, issue, return, and delete books. It also provides information about issued books and basic library statistics.

The project uses a JSON file to store library data so that the information can be saved and accessed when the program is run again.

---

## 🎯 Objectives

The main objectives of this project are:

- To develop a simple and user-friendly Library Management System.
- To manage book records efficiently.
- To allow users to search and view books.
- To manage book issuing and returning.
- To store library information using a JSON file.
- To provide basic library statistics.
- To apply Python programming concepts in a practical project.

---

## ✨ Features

### 1. Add Book
Allows the user to add a new book to the library.

### 2. View All Books
Displays all books currently available in the library.

### 3. Search Book
Allows the user to search for a particular book.

### 4. Issue Book
Allows a book to be issued and updates its status.

### 5. Return Book
Allows an issued book to be returned and updates its status.

### 6. Delete Book
Allows a book record to be deleted from the library.

### 7. View Issued Books
Displays the books that are currently issued.

### 8. Library Statistics
Displays basic statistics such as the total number of books and issued books.

### 9. Data Storage
Library information is stored in a JSON file so that data is not lost when the program is closed.
